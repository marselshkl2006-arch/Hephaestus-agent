# Первый запуск Гефеста

Привет! Это папка данных агента — здесь живут твой конфиг, база сессий,
память и логи. Ничего из этого не нужно никуда копировать вручную.

## Быстрый старт

1. **Конфиг провайдера**: скопируйте пример и поправьте под себя:

       cp config.example.toml config.toml

   Дефолт — Ollama на localhost:11434. Для облачных провайдеров ключ
   берётся из переменных окружения (ANTHROPIC_API_KEY и т.п.),
   для custom — можно задать прямо в конфиге.

2. **Telegram-бот** (опционально): получите токен у @BotFather и
   сохраните ОДНИМ из способов:
   - в чате агента: `/telegram save <токен>` (лежит в telegram_token.txt);
   - переменная окружения `TELEGRAM_BOT_TOKEN`.
   Токен персональный — в пакет не входит и никуда не отправляется.

3. **MCP-серверы** (опционально): `cp mcp.example.toml mcp.toml`.
   MongoDB и другие нестандартные источники подключаются именно так.

4. **Базы данных** (опционально): секция `[databases.NAME]` в config.toml.
   Секреты — через `{env:VAR}`, не в открытом виде.

## Что здесь появляется

- `config.toml` — основной конфиг (провайдер, права, БД, small_model)
- `state.db` — SQLite: сессии, ходы, tool-вызовы, журнал разрешений
- `telegram_token.txt` — токен бота (если сохраняли)
- `memory/` — долговременные факты агента (переживают перезапуск)
- `pending/memory/` — записи суб-агентов на ваше утверждение (/memory)
- `snapshots/` — git-снимки для /undo
- `logs/` — структурированные логи
- `tool-output/` — полные выводы больших результатов инструментов

Удаление этой папки = удаление истории и памяти агента.
