# ⚡ Гефест — AI Coding Agent

**Hephaestus** — это продвинутый AI-агент для разработки, который выполняет задачи через инструменты (tool calling). Он работает как ваш личный помощник в терминале, умеет читать и редактировать файлы, искать код, управлять памятью и задачами. Проект написан на Python и использует локальные или облачные LLM.

## ✨ Основные возможности

*   **Работа с файлами**: чтение, запись, редактирование, удаление, копирование, перемещение файлов и папок.
*   **Поиск и анализ кода**: поиск по содержимому (`grep`), поиск файлов по маске (`glob`), выполнение Git-команд.
*   **Управление памятью**: долговременное сохранение важной информации, поиск по памяти.
*   **Планирование задач**: создание списка задач, обновление статуса, отслеживание прогресса.
*   **Автоматизация**: создание и управление Cron-задачами, регистрация и выполнение собственных "навыков".
*   **Веб-инструменты**: поиск в интернете, загрузка и парсинг веб-страниц.
*   **Работа с Jupyter Notebooks**: чтение, создание, редактирование `.ipynb` файлов.
*   **Управление Docker**: просмотр, запуск, остановка контейнеров, просмотр логов.
*   **Генерация диаграмм**: создание ASCII-диаграмм для наглядного представления структуры классов, импортов и файлов.
*   **Интерактивное взаимодействие**: встроенный REPL (Read-Eval-Print Loop) с историей команд и подсказками.

## 🚀 Быстрый старт

### Требования
*   Python 3.10+
*   Доступ к работающей LLM или API (локальной, например, через Ollama, или облачной)

### Установка и запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/marselshkl2006-arch/Hephaestus-agent.git
    cd Hephaestus-agent
    ```

2.  Установите зависимости:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    ```

3.  Настройте переменную окружения для подключения к вашей LLM (в примере используется Ollama на локальной машине):
    ```bash
    export OLLAMA_HOST="ip локального LLM серера :11434"
    ```

4.  Запустите агента в интерактивном режиме:
    ```bash
    python3 -m src.hephaestus --provider ollama --model qwen2.5-coder:7b-instruct-q4_K_M или другая LLM
    ```

    **Пример быстрого запроса:**
    ```bash
    python3 -m src.hephaestus "создай файл hello.py с функцией say_hello"
    ```

## ⚙️ Команды и использование

В интерактивном режиме доступны команды для управления сессией:

*   `/help` — показать справку по командам.
*   `/tools` — вывести список всех доступных инструментов.
*   `/exit` или `/quit` — выйти из агента.
*   `/clear` — очистить экран.
*   `/reset` — очистить историю диалога.
*   `/history` — показать последние команды.
*   `/save` — сохранить текущую сессию.
*   `/load <id>` — загрузить сессию по ID.
*   `/models` — показать доступные модели.

## 🛠️ Детали реализации

Проект построен на следующих ключевых компонентах:

*   **LLM Клиент (`llm_client.py`)**: Абстрактный интерфейс для работы с различными провайдерами LLM, такими как Ollama, OpenAI, Anthropic и OpenRouter.
*   **Основной инструментарий (`real_tools.py`)**: Реализация базовых инструментов для работы с файловой системой, Bash и Git.
*   **Менеджер памяти (`memory_system.py`, `memory_tools.py`)**: Система долговременного хранения и поиска информации между сессиями.
*   **Планировщик задач (`scheduler.py`, `cron_tools.py`)**: Создание и управление периодическими задачами.
*   **Система навыков (`skill_system.py`, `skill_tools.py`)**: Механизм регистрации и выполнения пользовательских скриптов как новых "навыков".
